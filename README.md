# 기타 치며 노래하는 하치와레 — 3D 모형

브라우저에서 돌려 보는 단일 파일 three.js 모형입니다. 설치할 것이 없고 링크만 열면 됩니다.

**보기 — https://PUJUNE.github.io/hachiware-guitar-3d/**

## 조작

- 끌기 = 돌리기 · 휠 = 확대 · 오른쪽 끌기 = 옮기기
- 위쪽 단추 — 비스듬 · 정면 · 옆 · 얼굴 · 위
- 토글 — 연주(치는 팔·입·몸 흔들기) · 음표 · 이름표 · 외곽선 · 회전대
- 빠르기 막대 — 분당 60~160박
- 오른쪽 표의 줄을 누르면 그 부품만 남고 나머지가 흐려집니다

## 무엇을 보고 만들었나

- 몸통·팔·기타·그루터기 받침 — 3D 펜 공예가 사나고(3D SANAGO)의 영상
  「기타치며 노래하는 하치와레 만들기」(2026-10-18) 썸네일에서 비율을 읽었습니다.
- 얼굴·가르마·귀 — 하치와레 공식 피규어의 정면 그림에서 눈·볼·입·턱선의 윤곽을 그대로 떠서
  머리 타원면 위로 구부려 입혔습니다.

실측 치수가 아니라 그림에서 읽은 비율 근사입니다. 머리 가로를 66 으로 놓고 나머지를 같은 비로 환산했습니다.
움직임(치는 팔·벌어지는 입)은 그림에 없는 것을 더한 부분입니다 — 실물은 움직이지 않는 조형물입니다.

## 안에 든 것

- `index.html` — 모형과 조작, 설명판이 한 파일에 들어 있습니다
- `vendor/three.min.js` · `vendor/OrbitControls.js` — three.js r128 (MIT). 외부 요청이 없도록 저장소 안에 두었습니다

## 캐릭터 권리

하치와레는 『ちいかわ』(나가노)의 등장인물입니다. 이 모형은 팬이 만든 모사이며 공식 상품이 아니고,
캐릭터 자체의 권리는 원저작자에게 있습니다. 권리자의 요청이 있으면 내리겠습니다.
